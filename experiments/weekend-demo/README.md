# Froam Weekend Demo

This is a deliberately simple static page for proving the core Froam workflow:

1. Serve this folder with Froam.
2. Open the proxied page.
3. Edit the visible landing page.
4. Save to Repo.
5. Show the generated Froam files changed.

Run from the repository root:

```bash
npx froam dev --serve experiments/weekend-demo --port 4610
```

Then open:

```text
http://localhost:4610
```

Demo line:

> The page was the canvas, and the output is code.
